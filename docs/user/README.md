# DPC Android — documentazione d'uso

> 🚧 Prototipo: non usare su dispositivi di studenti reali.

Il DPC EduWISP si installa **durante la prima configurazione** del dispositivo, appena acceso o dopo un ripristino ai dati di fabbrica:

1. Nella schermata di benvenuto tocca sei volte lo stesso punto per aprire il lettore di QR code.
2. Inquadra il QR code generato dall'amministrazione di EduWISP: *Dispositivi → Token di registrazione*.
3. Android scarica il DPC, lo imposta come proprietario del dispositivo e lo registra sul server della scuola.

Dopo la registrazione l'app **EduWISP** mostra a chi usa il dispositivo che è gestito dalla scuola, lo stato della registrazione e le impostazioni che non è stato possibile applicare. La scuola riceve solo dati tecnici: modello, versione di Android e dell'agente, conformità alla policy.
